# Skill: takedown_google — Google (Search removal)

Goal: remove non-consensual fake/explicit imagery of an adult from Google Search results.

- Channel: Google's removal form for involuntary fake explicit imagery
  (https://support.google.com/websearch/troubleshooter/3111061).
- Provide: the URL(s) where the content appears, the search queries that surface it,
  the evidence block, notifier identity.
- Note: Google removes from SEARCH — the content itself may still need a platform/host
  takedown (see takedown_meta / takedown_x / takedown_host).
- Legal basis: DSA art. 16 ; Code pénal art. 226-8-1. Never state or invent a penalty.

## Steps (Computer Use)
1. Open the removal form; select "fake / involuntary explicit imagery".
2. Fill the fields from the case data; submit; capture the reference and report it back.

## Guardrails
Human confirmation gate passes first. DEMO: mock host + demo inbox ONLY — never a real submission.
